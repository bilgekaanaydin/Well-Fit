# WellFit

Haftalık yemek planı — telefonda uygulama gibi açılan tek sayfalık web arayüzü.

- `index.html` tek başına çalışır (fotoğraflar, yazı tipi ve ikonlar dosyanın içinde).
- Seçtiğin alternatif öğünler ve alışveriş listesi tarayıcıda saklanır.

## GitHub Pages ile yayınlama

1. GitHub'da yeni bir **public** repo aç (ör. `Well-Fit`).
2. `index.html` ve bu `README.md` dosyasını yükle (Add file → Upload files → Commit).
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
4. Birkaç dakika sonra adres: `https://<kullanıcı-adın>.github.io/Well-Fit/`

Telefonda açıp Safari'de **Paylaş → Ana Ekrana Ekle** dersen uygulama gibi açılır.

İkonlar: Flaticon UIcons · Fotoğraflar: Unsplash (Unsplash lisansı).
